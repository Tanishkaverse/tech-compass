# 🧭 Tech Compass

A free, beginner-friendly guide to technology careers for school and college students.

🔗 **Live site:** [https://techcompass-india.netlify.app]

## What it does

Tech Compass helps students understand the tech industry, choose a path, and follow a clear learning plan.

- **Career Explorer:** 9 fields (Software, Web, Mobile, AI/ML, Data Science, Cybersecurity, Cloud, UI/UX, Game Development) with overview, skills, difficulty, job roles, and a beginner roadmap
- **Career Quiz:** 6 questions that suggest matching fields
- **Learning Roadmaps:** step-by-step paths with progress tracking
- **Tech Dictionary:** plain-English explanations of common terms, with search and categories
- **Student Journey Guide:** advice for school, 1st/2nd year, internship, and placement stages
- **Myth Busters:** common misconceptions with facts
- **Resource Hub:** free and paid courses, books, platforms, and YouTube channels
- **Mentor Chat:** instant answers to common questions (rule-based, not a live AI model)
- **Dashboard:** progress saved locally in your browser
- **Feedback form**, dark/light mode, and a responsive layout

## Built with

- HTML, CSS, and vanilla JavaScript in a single file, with no frameworks or build step
- Hosted on Netlify (free plan)
- Netlify Forms for feedback

## Run it locally

1. Download or clone this repository.
2. Open `index.html` in your browser.

The feedback form only works when the site is hosted on Netlify.

## Deploy

1. Create a free Netlify account.
2. Drag the project folder onto the Netlify Drop page.
3. Replace `YOUR-SITE-URL` in `index.html`, `sitemap.xml`, and `robots.txt` with your address.

## Known limitations

- Progress is stored only on the visitor's device and is lost if browser data is cleared
- The mentor chat uses ready-made answers and can't handle every question
- There are no user accounts yet
